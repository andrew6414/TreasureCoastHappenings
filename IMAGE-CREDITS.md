# Image credits and usage notes

The app currently uses Wikimedia Commons images as **illustrative category/area imagery**. They are not photographs of the named restaurants, performers, specials, or events. The app labels them accordingly in listing cards and detail pages.

Each image is linked to its original file page so the source and license can be checked. No image from a business's website or social account has been copied into the app.

## Important

- The app's visible captions explicitly identify these as illustrative images, not photos of the named business or performer.
- CC BY and CC BY-SA images require attribution and a license link. CC BY-SA also has share-alike requirements for adaptations. The images are currently displayed unmodified.
- The public-domain seafood image does not require attribution, but credit is retained here for traceability.
- A listing should only be given an actual business/performer photo when a reuse license or other authorization for that exact photo is documented.
- Image files are currently loaded from Wikimedia Commons' file redirect URLs. If a source file is moved or removed, replace the URL and update this register.
