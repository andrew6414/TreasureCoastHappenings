# Treasure Coast Happenings

A mobile app for discovering restaurants, food and drink specials, live music, and local events across Florida's Treasure Coast.

## Starter features
- Photo-led home screen and category navigation
- Separate restaurant, specials, music, and event sections
- Search within each section
- Listing detail screens
- Weekly editor screen

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npx expo start`.
4. Open with Expo Go or use an iOS/Android simulator.

## Publishing notes
Listings currently use clearly identified sample placeholders. Replace them with verified business/event information and approved photos before public launch. The weekly editor is a front-end preview and currently stores its text only in app memory. A shared database, admin authentication, and a publishing workflow are required before updates can be distributed to all users.
